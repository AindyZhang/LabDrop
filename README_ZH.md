# ⚡ LabDrop

[English](README.md) | **简体中文**

> 把任意一台 Windows 电脑里的文件夹瞬间变成**局域网 + 公网共享的“网络U盘”**。  
> 告别插拔实体 U 盘、免注册免登录、支持整个多层文件夹上传下载、支持像真 U 盘一样一键打开本地窗口。

## ✨ 核心亮点

* **极简清爽桌面控制中心**：现代圆角卡片 UI，一键启动/停止，**无任何黑框命令行窗口**；关闭控制中心窗口后，服务器依然在后台稳定运行。
* **自定义任意文件夹当 U 盘**：随时选择本机任意磁盘目录作为共享 U 盘，同一局域网下不同电脑安装即拥有各自独立网址（多个独立 U 盘）。
* **支持整个文件夹收发**：
  * 拖拽或点击上传**单个文件 / 整个多层文件夹**（完整保留目录树），支持上传中断一键**重试 / 取消**；
  * 文件夹支持流式高速**打包下载 (`.zip`)**（保留外层文件夹外壳，大文件不爆内存）；
  * 内置 **WebDAV 网络磁盘** 与 **`labdrop://` 协议**，网页点一下 **「像真U盘一样打开」** 即可直接弹出 Windows 资源管理器窗口，免压缩 `Ctrl+C / Ctrl+V` 拷贝整文件夹。
* **独立公网访问热开关**：内置纯 Python 标准库公网穿透客户端（`bore.pub`），控制中心配备滑动开关，随时一键开启/禁止外网访问，不影响局域网使用。
* **多人并发 & 边传边下不中断**：多线程高并发服务器 + 原子临时文件写入保护 + 隐藏 `iframe` 下载隔离（完美兼容 iPad / iPhone Safari 与桌面浏览器）。
* **免装 Python · 自传播单文件安装包**：`LabDrop-Setup.exe` 仅 ~10.6 MB，无需管理员权限、目标电脑无需安装 Python；安装后网页底部自带说明书与安装包下载，实现局域网内零门槛自传播。
* **内置一键检查更新**：自动从本 GitHub Releases 只读检查新版本，有新版时一键下载最新安装包覆盖升级（保留原有配置与文件，不丢数据）。

## 🔒 100% 本地运行 · 隐私安全承诺

* **绝不上传任何隐私到云端**：所有资料完全保存在你自己的电脑硬盘上，无任何云盘服务器存储你的文件。
* **零统计、零追踪**：软件不收集任何使用日志、IP 或个人信息；检查更新仅发送一次只读请求读取 GitHub 公开版本号。
* **网络完全自主可控**：关闭“公网访问”滑动开关后，仅限同一局域网/Wi-Fi 访问。

## 🚀 快速使用（普通用户）

1. 前往本仓库右侧的 **[Releases](https://github.com/AindyZhang/LabDrop/releases)** 页面，下载最新的 **`LabDrop-Setup.exe`**；
2. 双击运行，点击 **【立即安装】**，3 秒完成，桌面自动生成黄色闪电图标 **`实验室网络U盘`**；
3. 双击桌面图标 → 选择要共享的文件夹 → 点击 **【启动网络U盘服务】**；
4. 复制 **局域网网址**（同 Wi-Fi 高速直传）或开启 **公网访问开关** 分享给同伴即可！

## 🛠️ 从源码自行构建（开发者）

本仓库源码零第三方 Python 依赖，使用 Windows 自带的 `.NET Framework 4.x` 编译器即可一键打包出单文件 `LabDrop-Setup.exe`：

```powershell
.\build.ps1
```

构建完成后，单文件安装程序将输出至 `dist\LabDrop-Setup.exe`。
